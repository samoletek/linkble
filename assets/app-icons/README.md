# App Icons

This folder will contain app icons for iOS and Android app stores.

## Required sizes:

### iOS App Store:
- 1024x1024 (App Store listing)

### iOS App (in Xcode):
- Generated automatically from 1024x1024

### Android Play Store:
- 512x512 (Play Store listing)
- 1024x500 (Feature graphic)
